# Diário de Aprendizado

## Aula 0 — Preparação do ambiente

### Ferramentas verificadas

- Ubuntu Linux
- SDK e runtime do .NET
- Git
- GitHub CLI
- Autenticação com o GitHub

### Conceitos aprendidos

- O SDK contém ferramentas para desenvolver e compilar aplicações.
- O runtime executa aplicações .NET.
- O Git registra o histórico do projeto localmente.
- O GitHub hospeda e compartilha repositórios pela internet.
