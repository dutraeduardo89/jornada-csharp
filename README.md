# Jornada de Aprendizado em C#

Este repositório documenta minha evolução nos estudos de C#, .NET, Git e GitHub.

O objetivo é registrar aulas, exercícios, desafios e projetos práticos, mostrando meu processo de aprendizado e minha evolução como desenvolvedor.

## Tecnologias utilizadas

- C#
- .NET
- Git
- GitHub
- Ubuntu Linux

## Organização do repositório

- `aulas/`: códigos produzidos durante as aulas.
- `exercicios/`: atividades de prática.
- `projetos/`: projetos maiores desenvolvidos durante os estudos.
- `docs/`: anotações e diário de aprendizado.
